# DEFAULT-GAME-TEMPLATE
Default game architecture.

Unity Version: 6.2

Packages: VContainer, MessagePipe, R3, UniTask, Addressables, DOTween, vFolder, vHierarchy, CustumToolbar, Cinemachine. 

Including:
 1. Extension Utils for variables
 2. interface IAssetLoder with AddressablesLoader script
 3. Scene managment with SceneSystem(scene loading async via IAssetLoder)
 4. interface IAudioSystem for any AudioSystem
 5. Free commercial use fonts and textures.
